# 54-й километр

Дачная игра к юбилею. Чистый HTML, CSS и JS, без сборки.

## Структура
- `index.html` — вся игра: интро, механика, финал, поздравление
- `assets/` — картинки в WebP

## Запуск локально
Открыть `index.html` в браузере.

## Деплой на Vercel
1. Залить папку в репозиторий на GitHub.
2. На vercel.com: Add New → Project → выбрать репозиторий.
3. Framework Preset: Other. Build Command и Output Directory оставить пустыми.
4. Deploy.

## Где что править
- Реплики друзей: `OWN` и `SHARED` в скрипте.
- Длительность игры: `DUR`, терпение до обиды: `PATIENCE`.
- Тексты интро: массив `STORY`.
- Поздравление: секция `#congrats`.
